# B360 Website

Premium one-page site for **B360** — African Talent, Built for the Global Stage.

## Stack

- Next.js 14 (App Router)
- Tailwind CSS
- Framer Motion
- GSAP + ScrollTrigger
- Lenis smooth scroll

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

```bash
npm run build
npm start
```

Ready to deploy on [Vercel](https://vercel.com).
